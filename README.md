# Майстерня поста

Редактор, у якому збирають кадр для Instagram: фон, шрифт, текст, і завантажують готовий PNG у точному розмірі.

Формати: стрічка 1080×1350, квадрат 1080×1080, stories / reels 1080×1920.

## Пост із фото і тексту

1. **+ Новий пост**.
2. Встав готовий текст поста як є. Редактор сам знайде хук для обкладинки, розкладе абзаци по слайдах (довгі поділить по реченнях), підбере заголовки, а останній абзац із записом на консультацію поставить на слайд із закликом. Рядок `---` примусово починає новий слайд, `**слово**` буде жирним. Перед збиранням у формі видно, як текст розкладено.
3. Додай фото: перше піде на обкладинку, наступні на слайди по черзі.
4. Перевір заклик до дії і підпис, натисни **Зібрати пост**.

Редактор складе обкладинку, слайди з фото або на кольоровому фоні й останній слайд із закликом до дії. Далі кожен слайд можна редагувати: текст, шрифти, кольори, макет, фото в рамці, порядок слайдів. **Усі слайди, ZIP** зберігає карусель (01.png, 02.png…) і підпис.

## Текст, відкат змін і календар

- **Текст на слайді** стоїть першим у правій панелі: усі тексти слайду можна правити прямо там. Подвійний клік по тексту в кадрі відкриває його поле.
- **↶ Відкотити** у шапці скасовує останню зміну (повзунок, текст, колір, видалення слайду чи поста), **↷** повертає її. Те саме роблять Ctrl+Z і Ctrl+Shift+Z.
- **Календар** показує контент-план по днях. Дату поста ставлять у панелі «Пост» або перетягуванням поста на день у календарі; кнопка «+» у дні створює новий пост на цю дату.

Пости і фото зберігаються лише в браузері на цьому пристрої. На GitHub і в інтернет вони не потрапляють, тому пост, зібраний на ноутбуці, не видно на телефоні.

## Запуск

```bash
npm install
npm run dev
```

Перевірка перед комітом:

```bash
npx tsc --noEmit && npm run build
```

## Публікація на GitHub Pages

Сайт збирається і публікується сам після кожного пушу в гілку `main` (файл `.github/workflows/deploy.yml`).

Один раз у репозиторії: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

На безкоштовному тарифі GitHub Pages працює лише з публічним репозиторієм, і сам сайт відкритий для всіх, хто знає адресу. Фото й тексти, які ти вставляєш у редактор, нікуди не відправляються: вони лишаються в браузері.

## Новий шаблон

1. Збери кадр у редакторі.
2. Натисни **Експорт JSON**.
3. Поклади файл у `src/templates/`. Порядок у списку задає назва файлу: `4-moy-shablon.json` стане четвертим.
4. Закоміть і запуш.

Поки шаблон не експортовано і не покладено в репозиторій, твої правки живуть лише в браузері й файли в git не змінюють. Кнопка **Скинути зміни** повертає шаблон до версії з репозиторію.

## Новий фон

Поклади зображення в `public/backgrounds/` і вкажи його в шаблоні:

```json
"background": {
  "kind": "image", "src": "backgrounds/moy-fon.jpg", "color": "#4D5270",
  "overlay": "#1E2030", "overlayOpacity": 0.25, "posX": 50, "posY": 50, "zoom": 1
}
```

Фото, обране в редакторі кнопкою **Обрати фото**, у JSON не потрапляє, бо воно лежить лише на твоєму комп’ютері.

## Шрифти

- **Onest** лежить у репозиторії: `public/fonts/onest/`, ліцензія SIL Open Font License 1.1 у `public/fonts/onest/OFL.txt`.
- Системні шрифти (Georgia, Arial, Times New Roman, Courier New, системний без зарубок) беруться з комп’ютера, на якому відкрито редактор.

**Свій шрифт, який не можна викладати у відкритий доступ**, у git не кладемо. Два способи:

1. У редакторі: блок тексту → **+ Свій шрифт з комп’ютера**. Працює, поки відкрита сторінка.
2. Локально назавжди: поклади `.woff2` у `src/fonts/local/` і перезапусти `npm run dev`. Назва файлу стане назвою шрифту в списку. Папка в `.gitignore`, тому файл не потрапить у репозиторій. На опублікованому сайті цього шрифту не буде.

Поки шрифт не завантажився, кнопка **Завантажити PNG** чекає, щоб у файл не потрапив кадр із запасним шрифтом.

## Структура

```
.github/workflows/deploy.yml   збірка і публікація на GitHub Pages
public/fonts/onest/            відкритий шрифт і його ліцензія
public/backgrounds/            фони для шаблонів
src/templates/                 шаблони JSON
src/fonts/local/               свої шрифти (не в git)
src/lib/                       формати, шрифти, малювання кадру, шаблони, автоверстка, фото
src/components/                пости, форма нового поста, слайди, кадр, панель налаштувань
claude-artifact/index.html     попередній конструктор каруселей
```
