# Каруселі iamsonia.psy

Візуальний шаблон для каруселей Instagram сторінки @iamsonia.psy.

## Що вміє

- **Конструктор**: пост з готової структури (обкладинка з фото і хуком, мем, порівняння «X vs Y», нотатка на фото, змішаний шрифт, заклик до дії), формат 1080×1350 (4:5), палітра шавлія / пудра / блакитний / графіт, @iamsonia.psy і номер на кожному слайді.
- **Розмітка тексту**: `**жирний**`, `_курсив-акцент_`, `->` стає стрілкою.
- **Перевірка**: тире, слово, яке блокує Instagram, гендерно забарвлені звертання, чекліст (хук, фото, мем на 2-му слайді, CTA, підпис, ЦА, оффер).
- **Експорт**: PNG одного слайду, ZIP усіх слайдів із підписом, копіювання всього тексту.
- **Контент-план**: тиждень із ціллю 3 каруселі, статуси від ідеї до публікації.
- **Ідеї**: теми, хуки, меми й метафори, з будь-якої можна одразу зробити пост.

## Де працює

Основна робоча версія відкривається як приватна сторінка в Claude: там пости, ідеї й фото синхронізуються між пристроями.
Якщо відкрити `index.html` просто в браузері, сторінка працює так само, але дані зберігаються лише в цьому браузері, а фото не запам’ятовуються після перезавантаження.
